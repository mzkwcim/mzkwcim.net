Rekordy klubowe – wyniki pływackie online

Aplikacja prezentująca najlepsze wyniki pływackie klubów i okręgów w czytelnej, filtrowanej formie.

Otwórz aplikację ↗Repozytorium ↗
01

Problem

Wyniki i rekordy pływackie są często rozproszone między plikami, serwisami wynikowymi i ręcznie prowadzonymi zestawieniami. Utrudnia to szybkie sprawdzenie rekordu dla konkretnej konkurencji, kategorii wiekowej lub długości basenu.

02

Co zbudowałem

Frontend do przeglądania rekordów klubowych i okręgowych z wyborem klubu, płci, basenu i kategorii wiekowej. Dane są pobierane dynamicznie z API i prezentowane w jednej spójnej tabeli.

03

Architektura

Warstwa prezentacyjna działa na Cloudflare Pages, API na Cloudflare Workers, a dane są przechowywane w D1. Repozytorium GitHub jest źródłem prawdy dla frontendu, a push do gałęzi głównej uruchamia automatyczny deployment.

04

Funkcje

Obsługiwane są różne kluby i okręgi, filtrowanie po płci, SCM/LCM i wieku oraz porządkowanie konkurencji w logicznej kolejności. Interfejs jest responsywny i dostosowany do telefonu i komputera.

05

Utrzymanie

Frontend jest wersjonowany w GitHubie i wdrażany automatycznie przez Cloudflare Pages. Dzięki temu zmiany wizualne i SEO można wprowadzać bez ręcznego uploadu plików.

Technologie

Cloudflare Pages · Cloudflare Workers · D1 · JavaScript · HTML · CSS
