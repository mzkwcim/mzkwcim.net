Swimtopia

Planowanie treningów, frekwencja, wykonanie zadań i analiza obciążeń dla trenerów pływania.

Case study i architektura ↗Kontakt →
01

Problem

Plany treningowe, frekwencja i wykonanie jednostek były rozproszone. Trudno było porównać założenia treningu z faktycznie zrealizowaną pracą.

02

Co zbudowałem

Zaprojektowałem aplikację React/FastAPI z modelem danych PostgreSQL dla sezonów, grup, zawodników i treningów. System obsługuje frekwencję, zadania i raportowanie.

03

Przebieg pracy

Plan sezonu i mikrocyklu → jednostka treningowa → frekwencja i wykonanie zadań → statystyki zawodnika i grupy.

04

Architektura

Frontend React, API FastAPI, PostgreSQL i Docker. Kod produkcyjny pozostaje prywatny; publicznie dostępna jest dokumentacja architektury i wdrożeń.

05

Dostępność

Publiczne case study jest dostępne. Osobne demo powstaje; strona nie publikuje danych zawodników.

Technologie i materiały

React · FastAPI · PostgreSQL · Docker
