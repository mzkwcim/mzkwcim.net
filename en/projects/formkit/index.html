FormKit

A utility library for creating repeatable forms and workflows from configuration rather than manual clicks.

Google Apps ScriptFormsSheetsJSON
▧
ON THIS PAGEProblem ↘Solution ↘Architecture ↘What it covers ↘Key takeaways ↘

Problem

Repeatedly building forms, validation and notifications took too much time.

Solution

JSON configuration describes questions and rules; scripts create forms, response sheets and basic email workflow components.

Architecture

Google Apps Script integrates Forms, Sheets and email, without a separate backend.

What it covers

  • Configuration-driven form creation.
  • Required fields and validation.
  • Linked sheets and notifications.

Key takeaways

A small reusable library can replace repeated one-off scripts.
