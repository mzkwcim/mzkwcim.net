KNOWLEDGE SYSTEM

Knowledge Graph

Technical knowledge stored as linked entities and relationships using Cloudflare D1, Workers and MCP.

Problem

Notes, documentation and experiment results quickly lose context. Text search alone does not explain how systems relate or what decisions were made earlier.

Solution

The design separates knowledge into domain-specific graphs, models entities and relationships, and makes them accessible through a web interface and tool integrations. AI can assist with suggesting links and organizing information.

Architecture

The frontend is published through Cloudflare Pages, with an integration layer built around Cloudflare Workers and APIs. Private resources are protected by Cloudflare Access. MCP-based operations and controlled approvals are part of the evolving design.

What it covers

  • Separate graphs for topics and technical domains.
  • Connections between concepts, systems, incidents and solutions.
  • Planned integration with external tools through APIs/MCP.
  • AI-assisted knowledge updates and relationship suggestions.
  • Explicit approval for destructive delete or merge operations.

Key takeaways

Useful knowledge systems need relationships, provenance and controlled updates more than sheer note volume. This project is evolving; planned integrations are not presented as completed.
