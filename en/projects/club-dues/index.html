Club Dues

Club membership and dues administration in a single web application.

Source code ↗Contact →
01

Problem

Club administrators need to track members, dues and payment status without reconciling several disconnected spreadsheets.

02

What I built

Club Dues provides a web interface for membership and fee administration, with workflows for viewing records and checking dues.

03

Workflow

View members → check dues and payment status → update administration records. The exact supported flow is documented in the public code.

04

Engineering

React and TypeScript application with Cloudflare deployment components. The source repository is public.

05

Availability

Public code is available. Contact me for demo access and to discuss the needs of a specific club.

Technology and source

React · TypeScript · Cloudflare
