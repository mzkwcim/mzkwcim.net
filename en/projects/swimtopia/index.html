Swimtopia

Training planning, attendance, execution tracking and workload reporting for swimming coaches.

Technical case study ↗Contact →
01

Problem

Training plans, attendance and session execution were maintained across separate tools and spreadsheets. That made it difficult to compare planned training with actual workload.

02

What I built

I designed a React/FastAPI application with a PostgreSQL data model for seasons, groups, athletes and training sessions. The application tracks attendance, tasks and reporting.

03

Workflow

Plan a season and microcycle → prepare a session → record attendance and task execution → review athlete and group statistics.

04

Engineering

React frontend, FastAPI backend, PostgreSQL and Docker. Private production code; public architectural documentation and deployment notes.

05

Availability

Public case study available. A separate public demo is in preparation; no real athlete data is published here.

Technology and source

React · FastAPI · PostgreSQL · Docker
